{% if lang == 'en' %}About Market Pulse{% else %}درباره مارکت پالس{% endif %}

{% if lang == 'en' %} Market Pulse is a high-performance, real-time financial tracking platform built with Python, Django, and Celery. Our asynchronous architecture continuously captures market fluctuations, processes real-time telemetry, and renders high-frequency financial charts without overloading the database. {% else %} سامانه مارکت پالس (Market Pulse) پلتفرمی با کارایی بالا جهت مانیتورینگ لحظه‌ای بازارهای مالی و رمزارزهاست که بر پایه معماری ماژولار پایتون، فریم‌ورک جنگو، ردیس و موتور زمان‌بندی Celery پیاده‌سازی شده است. این سیستم به صورت ناهمگام نوسانات قیمتی را استخراج کرده و بدون ایجاد بار اضافه بر دیتابیس، دیتای زنده را برای تحلیل در اختیار شما قرار می‌دهد. {% endif %}
